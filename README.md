## 📌 Project Overview
This repository contains the implementation of the **Harris Corner Detection** algorithm for both image and video processing tasks, as part of Lab 3 & 4. The project uses **Python** and **OpenCV** to detect and visualize corners in images and video frames.

---

## 📂 Repository Structure
- `harris_corner_detection_image.py` : Python script for image processing.
- `harris_corner_detection_video.py` : Python script for video processing.
- `harris_corner_detection_image.jpg` : Source image used for testing.
- `harris_corner_detection_image_V.mp4` : Source video used for testing.
- `screenshots/` : Folder containing "Before & After" screenshots for both image and video.

---

## 🛠️ Requirements
Ensure you have the following installed:
- Python 3.x
- OpenCV (`pip install opencv-python`)
- NumPy (`pip install numpy`)
